AI光通信学习路径：从信号路径到投资价值链

2026-06-03 · 产业思考 · 光通信

光通信名词太多，从名词表硬背很难记住。更有效的方法是按信号路径 + 投资价值链来理解——先搞懂"一束光怎么完成通信"，再把公司放到链条上。

一、最有效的理解方法：从"一束光怎么完成通信"开始

把AI光通信想成一句话：GPU产生数据，电信号太难远距离高速传输，所以要把电信号变成光信号，用光纤传出去，再变回电信号。

整条链路只有四步：

电信号产生
↓
电 → 光
↓
光纤传输
↓
光 → 电

对应产业链：

环节要理解的问题对应名词
发射端怎么把电信号变成光？EML、CW Laser、Driver、调制器
传输端光怎么传、怎么连接？光纤、FAU、连接器、OCS
接收端怎么把光变回电？PD、TIA
信号处理怎么修正高速传输失真？DSP、SerDes

按这个顺序学，不要一上来就看CPO、NPO、轻相干。

二、第一层：先搞懂"传统光模块"

这是最重要的起点。现在最先兑现业绩的，仍然是 800G / 1.6T 可插拔光模块。

交换芯片 / GPU
↓ 电信号
DSP / Driver
↓
EML 发光
↓
光纤传输
↓
PD 接收光
↓
TIA 放大
↓
DSP 修正信号
↓
电信号回到设备

先掌握5个词

优先级名词本质
1EML发射端激光器，把电信号变成光信号
2PD接收端探测器，把光信号变回电信号
3DSP光模块大脑，修正高速信号失真
4TIA / Driver接收端放大、发射端驱动
5FAU光纤和光芯片之间的精密接口

三、第二层：为什么从800G走向1.6T

不要先记数字，理解背后的变化：AI集群越大，GPU之间交换的数据越多，光模块速率必须提高。

升级结果与受益方：

升级结果谁受益
速率提高EML、PD、DSP、TIA、Driver 难度提升
模块数量增加中际旭创、新易盛、AAOI 等模块厂
光纤连接更多FAU、连接器、光纤厂商
测试更复杂VIAV、罗博特科等测试设备

四、第三层：CPO / NPO

传统光模块插在交换机面板上，芯片到光模块之间要走一段电信号。速率越高，电信号越难走远，功耗变高、信号失真、散热压力变大。

行业开始想：能不能把光模块搬得离芯片更近？这就产生了NPO和CPO。

NPO（近封装光学）：光引擎靠近GPU/ASIC，但没有完全封进去。中间方案，比CPO量产难度低。
CPO（共封装光学）：光引擎和交换芯片/ASIC封装在一起。更激进，长期空间大，但量产难度更高。

五、按投资重要性，目前最该先弄懂的顺序

第一优先级：800G / 1.6T 传统光模块（业绩最先兑现）

AI 集群扩大
↓
800G / 1.6T 光模块放量
↓
模块厂收入增长
↓
EML / PD / DSP / FAU 紧缺
↓
上游器件、芯片、测试设备涨价或订单增加

第二优先级：CPO / NPO（下一阶段估值拔高）

传统铜互联/可插拔模块接近瓶颈 → 光引擎向芯片靠近 → NPO先导入 → CPO中长期放量 → CW Laser/硅光/FAU/测试设备受益。

第三优先级：OCS / 轻相干（架构级变化）

AI集群越来越大 → 网络调度复杂化 → 传统交换效率不够 → OCS/轻相干进入大厂方案。更适合跟踪Google、Meta、Amazon的数据中心架构变化。

第四优先级：玻璃基板/Glass Interposer（先进封装）

GPU越来越大 → HBM越来越多 → CoWoS面积不够 → 玻璃Interposer成为新路线。节奏更远，不要和当前光模块业绩线混在一起。

优先级名词学到什么程度就够
1800G / 1.6T光模块速率升级，直接对应出货放量
2EML发射端激光器，当前高速模块关键瓶颈
3PD接收端探测器，200G/lane可能紧缺
4DSP光模块信号处理芯片，价值量高、功耗也高
5FAU光纤和光芯片的精密连接器件
6CW LaserCPO/硅光外部光源核心
7NPO光引擎靠近GPU，可能比CPO更早落地
8CPO光引擎和芯片共封装，长期方向但节奏不确定
9硅光把光器件集成到硅工艺平台上
10OCS全光交换，主要看Google等大厂路线

十、最简学习清单

先学这6个：

  1. 800G / 1.6T：为什么光模块升级？
  2. EML：为什么发射端光源紧缺？
  3. PD：为什么接收端也会缺？
  4. DSP：为什么高速光模块离不开信号处理？
  5. FAU：为什么光芯片和光纤连接很难？
  6. NPO / CPO：为什么光要越来越靠近芯片？

这6个搞懂后，再学OCS、轻相干、玻璃基板，难度会下降很多。
