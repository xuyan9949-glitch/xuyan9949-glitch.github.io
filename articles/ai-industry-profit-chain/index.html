AI产业链收益排序分析

2026-05-25 · AI · 产业链 · A股

AI基础设施从GPU单点采购，升级为整机柜、网络互联、光模块、PCB、液冷、电力、算力调度的全栈扩张。最先受益的是硬件链；最卡脖子的是HBM、先进封装和高速互联；利润最容易体现的是光模块、高端PCB、服务器配套和液冷电源。

一、利润最容易体现的地方

第一梯队：光模块/高速互联

利润兑现最直接、弹性最大的方向。光模块是消耗型升级品——AI集群每升级一代，交换机/网卡/光模块/光纤连接密度同步上升。

第二梯队：PCB/CCL/高速材料

高端高速PCB、AI服务器PCB、交换机PCB、ABF/BT载板、高端CCL。但AI产品真正需要的是高端高速高频材料，不是所有CCL都同等受益。

第三梯队：服务器/整机柜/液冷/电源

Vera Rubin 机柜 Q3 起批量交付，CPU/互联/交换等价值量提升。收入确认快但利润率未必最高。

二、最卡脖子的五个环节

环节说明主导者
HBMGPU核心瓶颈SK hynix/Micron/Samsung
先进封装/CoWoSGPU和HBM高效连接的关键TSMC/ASE主导
高速互联/光模块/交换CPO/LPO/LRO路线竞争COHR/LITE/AAOI/AXTI
电力/液冷/数据中心缺电、缺地、缺变压器CEG/OKLO/VRT
算力调度/算力网运营国家级基础设施利润兑现慢于硬件链

三、四维度排序

进攻排序

光模块 → 高端PCB → 液冷/电源 → HBM/先进封装 → 服务器/整机柜 → 运营商/算力网 → AI应用

利润兑现速度排序

光模块 → 高端PCB → 服务器/整机柜 → 液冷/电源 → 半导体设备材料 → 运营商 → 算力调度 → AI应用

卡脖子程度排序

HBM → 先进封装 → 高速互联 → 电力/液冷 → 算力调度 → 国产AI芯片 → 数据治理

A股短期弹性排序

光模块/CPO → PCB/CCL → 液冷/电源 → 国产算力 → 算力网/调度 → 数据治理 → 端侧AI

最核心的一句话：AI基础设施从GPU单点采购，升级为全栈扩张。最先受益硬件链，最卡脖子HBM和先进封装，利润最容易体现光模块和高端PCB。
