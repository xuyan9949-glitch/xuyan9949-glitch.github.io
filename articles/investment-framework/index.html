投资框架笔记

2026-05-28 · 框架 · A股 · 美股

一、底层信念

投资不是奖励过去，而是定价未来新增量。

"懂光模块"不是成功的原因。成功的原因是：

  1. 美股科技巨头 CapEx 上升
  2. → AI 不是概念，是真金白银的基础设施建设
  3. → 模型能力带来算力需求
  4. → 算力需求落到互连、存储、电力、液冷、PCB、光模块
  5. → 最早确定收钱的是卖铲子的人

关键差异：不是从 A 股题材开始看，而是从全球科技巨头资本开支开始看。这比单纯追热点高一层。

二、克服"旧框架钝化"

过去十几年中国资产的代际主线：

时代核心资产
城镇化地产、建材、工程机械、周期品
消费升级白酒、调味品、免税、医美
移动互联网平台、电商、游戏、内容
新能源光伏、锂电、储能、电动车

每一代主线都有生命周期。

当市场给稳定消费品极高估值时，必须问——未来新增量从哪里来？

  • ✅ 商业模式成熟
  • ✅ 现金流稳定
  • ✅ 品牌壁垒强
  • ❌ 增量空间有限

估值包含了过高的未来预期，但真实增长很慢 → 从"确定性溢价"变成"过去成功的幻觉"。

三、Follow the Money

真正的大产业趋势，不会只停留在口号里，而是体现在：

  1. 巨头资本开支
  2. 供应链订单
  3. 产能扩张
  4. 上游材料涨价
  5. 设备交付周期拉长
  6. 财报指引上修
  7. 客户认证节奏加快

AI 产业链观察顺序：

云厂商 CapEx
→ GPU / ASIC 出货
→ HBM / CoWoS / 先进封装
→ 光模块 / 交换机 / 网卡
→ PCB / CCL / 高速材料
→ 电力 / 液冷 / 数据中心
→ 应用变现

四、三类钱的框架

① 0 到 1 — 预期钱

维度内容
阶段技术验证期
赚什么钱认知提前量、预期差
典型风险验证失败、收入迟迟不兑现
适合看技术路线、客户验证、样品进度、认证周期、潜在TAM、产业趋势位置

② 1 到 100 — 确定性钱

维度内容
阶段规模复制期
赚什么钱订单、收入、利润增长
典型风险估值已反映大部分预期
适合看订单、收入增速、毛利率、净利润、现金流、扩产能力、客户结构、产能利用率

③ 供需失衡 — 紧缺钱

维度内容
阶段紧缺涨价期
赚什么钱价格弹性、利润弹性
典型风险扩产后供给反转
适合看价格、库存、扩产、交付周期、下游接受度、新增供给时间表

⛔ 周期股被成长股估值化时要特别谨慎。

买卖点对照

类型买点卖点
0 到 1市场没充分理解，验证刚开始所有人开始讲故事，但收入没跟上
1 到 100订单、业绩持续兑现，估值还能接受增速放缓、估值过满、机构拥挤
供需失衡价格上涨、库存低、扩产未释放扩产放量、价格松动、毛利率见顶

五、投资框架（三步走）

第一步：判断时代主线

不看来什么涨得多，而是看：

  • 未来社会生产力往哪里迁移？
  • 钱流向哪里？
  • 哪个环节从概念变成资本开支？

第二步：找物理入口

产业趋势物理入口
移动互联网智能手机、基站、流量入口
新能源车电池、电机、电控、充电
光伏硅料、硅片、电池片、组件、逆变器
AIGPU、HBM、光模块、交换机、电力、液冷、PCB

投资上真正有价值的：

  • 谁是新增需求的第一承接方？
  • 谁是扩产最慢的瓶颈？
  • 谁的价格最容易上涨？
  • 谁最早反映到收入和利润？

六、A 股特有的轮动规律

A 股最容易出现的问题：逻辑是真的，但买点已经不对了。

龙一业绩兑现
→ 龙二补涨
→ 上游材料扩散
→ 设备耗材扩散
→ 低位小市值补涨
→ 参股 / 蹭概念
→ 退潮
层级特点
🥇 真龙头有订单、有利润、有客户认证
🥈 直接受益产业链位置清楚，弹性略弱
🥉 上游瓶颈可能有涨价和供需错配
设备耗材节奏慢半拍，但确定性可能更强
低位补涨更多是情绪交易
蹭概念主题弹性大，基本面弹性弱

不能只问"它是不是 AI 产业链"，要问"它在产业链里的哪一层，赚哪一种钱，现在走到哪一段"。
