美光FY2026 Q3财报：机构投资者视角拆解

2026-06-27 · 美股 · 财报分析

核心判断

这不是一份普通的"存储涨价周期财报"，而是一份开始证明存储行业商业模式可能发生变化的财报。最重要的并非Q3利润有多夸张，而是美光首次用长期协议、价格底线、客户预付款，把未来存储周期的下行风险部分锁死。

但也不能只看多：Q3增长高度依赖ASP而非出货量；Q4价格涨幅已经明确放缓；长期协议虽然保护下限，也会限制部分现货涨价带来的上行弹性。

一、财报究竟超预期在哪里

核心数据如下：

指标FY26 Q3实际环比变化/特征
营收414.6亿美元+74%
毛利率84.9%+10个百分点
非GAAP EPS25.11美元+106%
经营现金流253.9亿美元占营收61%
调整后自由现金流183亿美元历史新高
DRAM ASP—环比上涨60%出头
NAND ASP—环比上涨80%中段
DRAM出货量—仅低个位数增长
NAND出货量—仅中个位数增长

1. 最大超预期：涨价能力远高于正常周期

DRAM收入环比增长67%，但bit出货只增长低个位数，意味着绝大部分增长来自价格；NAND收入环比增长99%，bit出货只增长中个位数，同样几乎全部由ASP推动。

这说明当前不是"需求温和恢复"，而是供应分配权和定价权已经明显转移到存储厂商手里。更重要的是，涨价并不局限于HBM：

  • 云存储部门毛利率83%；
  • 核心数据中心部门毛利率87%；
  • 手机与客户端部门毛利率87%；
  • 汽车与嵌入式部门毛利率79%。

当前利润爆发是全产品线的供需紧张，而不只是高毛利HBM拉动。

2. 数据中心收入质量明显强于市场通常理解

美光数据中心收入超过250亿美元，年化超过1,000亿美元；其中数据中心SSD收入超过50亿美元，环比翻倍以上。市场过去主要把美光理解成"HBM+DRAM涨价"，但本季度证明NAND和企业级SSD已经成为第二条利润主线。

3. 现金流质量极强

183亿美元季度自由现金流，是这份财报最容易被利润表掩盖的亮点。美光同时偿还了大量债务，期末净现金约244亿美元，资产负债表由过去周期高点的"扩产风险"变成了"现金富余"。

10-Q显示，现金及投资从上一财年末约119亿美元增长到301亿美元；债务从约146亿美元降至57亿美元。

4. 库存结构支持供给紧张判断

期末库存为85.7亿美元，较上一财年末基本持平，但产成品库存从10.9亿美元下降至6.2亿美元。收入暴增、产成品库存下降，说明并不存在依靠渠道压货或库存堆积实现收入增长的迹象。

二、哪些地方低于最乐观预期，或者存在隐忧

这里的"低预期"不是说结果差，而是指没有财报标题看起来那么无限乐观。

1. 增长主要靠价格，而不是出货量

DRAM和NAND出货量增长都很有限。存储厂商的利润弹性因此极强，但估值也会对ASP拐点极度敏感。这是一份高质量的供给短缺财报，但还不是一份证明终端销量全面爆发的财报。

2. Q4增长速度正在正常化

Q4指引为：营收500亿美元；毛利率约86%；EPS 31美元。表面看，营收环比增长约20.6%，EPS增长约23.5%。但FY26 Q4是14周季度，而Q3为13周季度。按单周收入折算，实际环比增速约为12%，而不是21%。

同时，营收预计增加约85亿美元，毛利率却只从84.9%提升至86%，公司还明确表示：价格上涨速度将显著放缓。

这意味着Q3可能是利润率扩张速度最快的季度，未来增长更多来自收入基数扩大，而不是毛利率继续跳升。

3. 已经出现需求弹性管理

公司把2026年服务器出货增长预测从低双位数上调至高十几，但同时指出，客户正在适度降低单台服务器DRAM容量增长，以便在内存配额有限时尽可能多生产服务器。

这句话非常重要：需求没有消失，但客户已经开始进行配置优化和容量压缩。如果内存价格继续快速上涨，这种行为可能从服务器扩散到PC、手机等市场。手机及客户端部门本季度收入上涨49%，但bit出货量反而下降，也是同一信号。

4. 资本开支明显抬升

Q4资本开支约100亿美元，较Q3约71亿美元上升约41%；FY27单季度资本开支预计还会高于Q4，全年运营费用也预计增加约10亿美元。不过需要区分：FY27增加的资本开支一半以上是厂房和洁净室建设，而不是马上形成产能的设备投入。因此它会压低中期自由现金流率，但不会立即解决2026—2027年的供应短缺。

5. 暂时没有回购

Q3产生183亿美元自由现金流，但没有股票回购。管理层表示，要到2026年12月9日之后，受到CHIPS协议限制放松，才计划提高资本回报。因此近期EPS增长主要来自经营增长，而不是股本收缩。

三、电话会新增的真正重要信息

需要说明：上传材料包括管理层Prepared Remarks，但没有完整Q&A实录。以下属于电话会准备发言新增信息，不包含分析师问答中的增量。

1. 长期客户协议SCA，是整场电话会的核心

美光已经签署16份战略客户协议：

  • 通常期限为2026—2030年，汽车协议通常为三年；
  • 覆盖约20%的DRAM销量；
  • 覆盖约三分之一NAND销量；
  • 包括4家超大型客户、3家中型客户及多家汽车客户；
  • 采用take-or-pay，客户必须按约采购或付款；
  • 14份协议按最低价格计算的累计收入约1,000亿美元；
  • 已签协议对应220亿美元客户存款及财务承诺，其中约180亿美元为现金存款。

更关键的价格结构：

  • 大型协议通常以2026年二季度现货水平附近作为现有产品价格上限；
  • 同时设置长期价格下限；
  • 即使按照价格下限执行，美光声称毛利率仍显著高于历史任何周期峰值；
  • 全部目标协议签署后，预计约一半以上公司收入处于SCA覆盖下；
  • 约40%公司收入可能采用固定价格，或以当前高位价格作为上限。

这是非常强的下行保护，但也是一把双刃剑：如果未来现货价格继续暴涨，部分合同收入的价格上限会限制美光的短期利润弹性。因此SCA本质是：牺牲部分周期顶部收益，换取长期利润下限和现金流确定性。

2. 1,000亿美元RPO不能直接当作未来全部收入

公司强调，1,000亿美元是按最低采购量和最低价格计算的保守履约义务，并不代表未来实际收入；实际收入预计显著高于该数字。同时，客户存款计入融资现金流，而不是经营现金流或自由现金流，且会在合同后半段逐步返还或抵扣。因此不能把180亿美元现金存款简单视为"无成本永久现金"或直接用于估值加总。

3. HBM4进度明显快于此前产品

美光已经实现超过10亿美元HBM4收入，HBM4 12层产品的量产爬坡速度是HBM3E 12层的两倍，达到成熟良率的速度也预计明显更快。

这一信息的意义是：市场对美光HBM的主要担忧已经从"能否进入客户供应链"，转向"能拿到多大份额、良率提升多快"。如果后续两个季度继续显示HBM4收入快速增长，美光的估值逻辑会逐渐从纯存储周期股转向"AI高性能内存平台"。

4. NAND供给约束比市场想象得更结构化

行业正在把部分NAND洁净室空间转向DRAM，有限的洁净室资源又被HBM和先进DRAM占用。由此导致NAND供给增长受到挤压。这解释了为什么本季度NAND ASP上涨幅度甚至高于DRAM，也解释了数据中心SSD收入翻倍。

5. 2028年供应改善，但看不到供需平衡时间

管理层预计2028年行业供应会逐步改善，但目前仍无法判断供应何时能追上需求。这是比"短缺持续至2027年"更激进的表述：公司实际上认为，新增晶圆厂投产速度、工人短缺、审批、电力基础设施以及制程复杂度，将持续限制有效bit供给。

四、哪些信息市场可能还没有充分定价

正面未充分定价一：估值体系可能发生变化

过去市场给美光低估值，是因为其利润高度周期化：价格上涨时盈利暴增，价格下跌时可能亏损。SCA引入后，如果一半以上收入最终获得长期采购承诺，且合同底价对应的毛利率高于历史周期峰值，那么美光的"正常化利润"可能远高于市场过去采用的中周期利润。

这不只是盈利预测上调，而是可能带来估值方法变化：从周期底部/顶部利润折现，转向合同覆盖收入、自由现金流稳定性和资本回报估值。不过重估不会一次完成。市场需要验证合同是否真正执行、客户是否集中、价格条款是否稳定，以及行业下行时take-or-pay是否具备足够约束力。

正面未充分定价二：NAND可能是下一阶段盈利预期差最大的方向

当前市场注意力集中在HBM，但本季度：NAND ASP环比上涨80%中段；数据中心SSD收入超过50亿美元并翻倍；三分之一NAND销量已经被长期协议覆盖；美光2026年NAND供应增长预计低于行业。因此下一个季度真正可能继续上修的，不一定只是HBM，而可能是企业级SSD和高端NAND。

正面未充分定价三：FY27高资本开支并不等于FY27立刻供应过剩

市场看到资本开支上升，容易立即交易"扩产—供给增加—价格下跌"。但美光新增产能的主要时间点是：台湾铜锣现有厂2027年中开始有意义出货；新加坡HBM先进封装2027年上半年贡献；爱达荷ID1 2027年中首片晶圆；ID2 2028年底；新加坡新NAND洁净室2028年下半年。因此FY27资本开支上升，短期更多是设备、洁净室和在建工程订单增加，而不是2026年内出现大量bit供给。

负面未充分定价一：SCA会降低周期下行风险，也会降低顶部弹性

部分合同以当前CQ2高价格作为价格上限。如果未来现货价格继续上涨，合同内销量不能完全跟涨。美光正在从"高弹性现货资产"转向"高确定性合同资产"。这有利于估值中枢，却可能降低极端牛市中的利润上修速度。

负面未充分定价二：Q4数字受到14周季度放大

500亿美元营收看起来极强，但剔除多出的一周后，收入运行速率增长约12%。仍然优秀，但明显低于表面21%的环比增速。如果市场只交易500亿美元整数关口，而没有调整季度长度，可能高估了短期增长斜率。

五、对产业链的影响

1. 存储原厂：整体利好，但美光正在率先争夺商业模式话语权。如果SCA模式被客户接受，同行可能跟进长期采购、预付款和价格底线机制，令整个行业从过去的"短周期现货竞争"逐渐向"长期产能预订"演化。HBM弹性最直接对应海力士、三星和美光；NAND涨价和数据中心SSD逻辑更直接对应铠侠、闪迪、三星及美光。

2. 半导体设备：确定性增强，兑现时间集中在2027—2029年。美光明确披露与ASML签署多年EUV设备供应协议，用于1δ及后续节点。直接受益方向包括EUV光刻、刻蚀与沉积设备、薄膜量测检测、洁净室及厂务工程。

3. HBM先进封装链：需求确定性继续上升。HBM4更快爬坡以及新加坡先进封装产能扩张，利好TSV及深硅刻蚀、混合键合/热压键合、晶圆级测试、封装基板、热界面材料和散热。

4. 数据中心SSD链：可能迎来第二轮重估。AI Agent增加上下文存储，使企业级SSD需求从单纯"服务器配套"变为AI基础设施独立瓶颈。利好NAND原厂、企业级SSD控制器、固件和高速接口生态。

5. 下游云厂商和服务器OEM：成本压力和供应安全同时上升。下游可能采取三种应对：优先保障高毛利AI服务器、降低部分服务器单机DRAM容量增长、通过涨价和长期采购转嫁成本。

6. PC、手机和消费电子：高端相对安全，低端承压。公司预计PC和手机销量仍可能下降，但行业收入增长，说明高端产品提价和产品组合升级正在抵消销量压力。

六、未来两个季度最重要的跟踪指标

  1. DRAM与NAND ASP环比变化。Q4"价格涨幅放缓"究竟是从60%—80%降至20%—30%，还是迅速降至个位数？Q1 FY27的ASP走势比Q4绝对营收更重要。
  2. SCA新增签约、RPO和客户存款。覆盖收入比例是否向50%推进；RPO是否继续大幅增加；是否存在合同修改或客户重新谈判。
  3. HBM4收入、良率和客户认证。收入是否从10亿美元快速放大；12层良率；在新客户中的份额；新加坡封装产能投产进度。
  4. NAND与数据中心SSD收入。若继续高增长而ASP仍强于DRAM，说明市场仍低估NAND短缺持续性。
  5. 毛利率能否稳定在85%以上。下一步重点不是毛利率还能升到多高，而是价格涨幅放缓后能否维持。
  6. 终端需求是否出现更明显的价格弹性。重点看服务器平均DRAM容量是否继续被削减、PC和手机bit出货是否持续下降。
  7. 资本开支与自由现金流的匹配。FY27单季度资本开支将高于100亿美元，需确认自由现金流能否覆盖建厂、研发、客户存款返还和未来回购。

七、如果只允许保留三个结论

第一，当前美光利润增长的核心是定价权，而不是出货量。DRAM和NAND收入爆发几乎全部来自ASP，说明供给短缺真实且广泛，但也意味着未来股价对价格拐点会极度敏感。

第二，SCA比本季度EPS更重要。Take-or-pay、价格底线、1,000亿美元最低合同收入和180亿美元客户现金存款，正在把美光从高波动周期公司改造成部分合同化的现金流资产；但价格上限也会牺牲部分顶部弹性。

第三，未来两个季度真正要验证的不是"存储还缺不缺"，而是"涨价放缓后，85%以上毛利率能否维持"。如果毛利率稳定、SCA继续扩张、HBM4和企业级SSD继续增长，美光的估值中枢仍有上移空间；如果终端配置削减扩大、ASP快速见顶，则市场会重新把它按传统周期股定价。
