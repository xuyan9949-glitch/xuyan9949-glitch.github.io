东山精密日内做 T 思路笔记

2026-06-12 · A股 · 交易框架

核心是帮你建立一套判断逻辑：什么时候该做、做哪种T、什么时候坚决不动。

一、做 T 的本质

做 T 不是预测涨跌，而是用底仓在日内波动里优化成本。

类型做法适合场景
正 T低位买入，冲高卖出原有底仓板块强，个股回踩
倒 T冲高卖出底仓，回落买回个股冲高过快，板块不跟

做 T 的目的不是每天都操作，而是：在不破坏中线仓位的情况下，利用日内波动降低持仓成本。

二、第一原则：先判断"今天值不值得 T"

东山精密这种票，不能只看自己分时。它现在是复合逻辑：AI PCB + 光模块/光芯片 + 消费电子/精密制造。

所以做 T 前要先判断三个层面：大盘环境 → 板块环境 → 东山自身结构。如果这三层不配合，就算价格看着便宜，也不一定能做。

三、判断顺序

1. 先看大盘

东山精密是偏成长、高弹性的票。大盘环境差时，做 T 的容错率会明显下降。

大盘状态做 T 思路
大盘强可以找低吸 T
大盘震荡只做高质量点位
大盘弱少低吸，更多考虑冲高卖 T
大盘跳水不主动低吸

关键点：大盘如果在快速杀跌，个股支撑位容易失效。不能因为东山跌到 5 日线、VWAP、昨日低点，就机械低吸。

2. 再看光模块板块

重点看：中际旭创、新易盛、天孚通信、太辰光、光迅科技、剑桥科技

光模块状态对东山做 T 的含义
光模块强东山低吸成功率提高
光模块弱东山冲高容易回落
光模块强、东山弱东山相对弱，不能盲目低吸
光模块弱、东山强东山可能有独立资金，需要重点观察

3. 再看 PCB / AI PCB 板块

重点看：沪电股份、胜宏科技、生益科技、深南电路、景旺电子、鹏鼎控股

PCB 状态对东山做 T 的含义
PCB 强东山有基本盘支撑
PCB 弱东山冲高容易被砸
PCB 和光都强双逻辑共振，低吸质量高
PCB 和光都弱原则上不低吸

最好的做 T 环境是：光模块强 + PCB 强 + 东山只是日内回踩。这说明逻辑没坏，只是给了你日内波动。

四、再看东山自身技术结构

东山自己的技术线也重要，但它是确认工具，不是单独买卖理由。

指标作用
5 日线判断短线趋势是否健康
10 日线判断趋势有没有转弱
20 日线判断中短期支撑
VWAP判断日内多空控制权
昨日高点日内压力位
昨日低点日内支撑位
今日开盘价判断强弱分界
开盘15分钟高低点判断日内节奏

5 日线决定今天能不能考虑做；VWAP 决定日内什么时候做。

五、三种操作场景

场景一：低吸 T（正 T）

低吸 T 的本质是：板块逻辑没坏，东山只是被动回踩。

较好的低吸条件：

  1. 光模块或 PCB 至少一个强，最好两个都强
  2. 大盘没有跳水
  3. 东山回踩 VWAP、昨日收盘、5 日线或昨日低点附近
  4. 下跌没有明显放量
  5. 跌到某个位置后不再创新低
  6. 预期反弹空间至少有 0.8%—1.2%

典型状态：光模块 +1.5%，PCB +1.0%，东山 -0.5%，回踩 VWAP 附近，成交量没有异常放大，跌不动了。这时可以理解为板块还在，东山只是盘中洗一下。

场景二：冲高卖 T（倒 T）

冲高卖 T 的本质是：东山冲得比板块快，但板块没有确认，存在回落风险。

适合卖 T 的条件：

  1. 东山涨幅明显大于光模块和 PCB
  2. 光模块、PCB 没有同步拉升
  3. 东山远离 VWAP
  4. 冲高后量能跟不上
  5. 接近昨日高点、前高或整数压力位
  6. 大盘或创业板开始走弱

典型状态：东山 +3%，光模块 +0.5%，PCB +0.3%，创业板走弱，东山远离 VWAP，成交量没有继续放大。这种情况不是强趋势确认，而是个股脉冲拉升，适合卖一部分底仓，等回落再买回。

场景三：不动

这是做 T 里最重要的一类。不是每天都要 T。很多时候，最优解就是不动。

必须不动的情况：

  1. 光模块和 PCB 同时弱
  2. 大盘正在跳水
  3. 东山跌破 VWAP 后没有收回
  4. 东山横盘在 VWAP 附近，没有价差
  5. 预期价差小于 0.8%
  6. 板块信号混乱
  7. 东山强趋势放量上攻，卖 T 容易卖飞

技术线只是位置，不是买点。板块确认才是前提。

六、核心框架

大盘不杀 → 光/PCB 不弱 → 东山有支撑 → 价差够 → 才做 T

顺序不能反。错误顺序：东山跌了 → 快到 5 日线了 → 我买一点。正确顺序：大盘没坏 → 板块没坏 → 东山只是回踩 → 跌到关键位置 → 有反弹空间 → 再考虑低吸。

七、关键纪律

  1. 双板块弱，不低吸。 光模块弱 + PCB 弱 + 东山也弱 → 不是低吸，是共振下跌
  2. 东山弱于板块，不急着低吸。 先等它重新站上 VWAP，或者跌幅明显收窄
  3. 东山强于双板块，不要乱卖飞。 有独立资金走主升时，卖了容易买不回来
  4. 价差不够，不做。 预期价差小于 0.8% 不做。理想 T 空间：1.0%—2.0%

八、正 T 和倒 T 怎么选

正 T（低吸再卖）倒 T（先卖再买）
适合板块强、东山回踩、大盘没坏、跌到 VWAP 或 5 日线附近、下跌缩量东山冲太快、板块没跟、大盘不稳、接近压力位、远离 VWAP
逻辑主线没坏，个股给了低吸窗口个股短线涨过头，先卖部分底仓，等回落接回

九、最值得做的几种 T

高质量低吸 T： 大盘稳 + 光模块强 + PCB 强 + 东山回踩 VWAP + 下跌缩量 + 重新站回分时均线

高质量卖 T： 东山快速拉升 + 涨幅明显强于板块 + 远离 VWAP + 量能没有继续放大 + 接近昨日高点或前高

高质量不动： 板块混乱 + 东山横盘 + 价差不够 + 信号不清楚。能忍住不做，本身就是提高 T 质量。

十、常见错误

错误问题
只看东山分时容易忽略板块共振
只看 5 日线技术位置不等于买点
跌了就低吸可能接到破位
涨了就卖 T强趋势容易卖飞
板块弱还低吸成功率低
价差太小也做消耗精力和纪律
做错不复盘下次还会犯同样错误

十一、最终决策表

问题是/否
大盘有没有跳水？
光模块板块是否不弱？
PCB 板块是否不弱？
东山是否只是回踩，不是破位？
当前是否靠近有效支撑或压力？
预期价差是否超过 0.8%？
如果做错，失败位置在哪里？
这次 T 是否值得动用？

如果前面几个答案不清楚，就不要做。

最终一句： 东山精密做 T 的关键不是找最低点和最高点，而是判断今天这个波动，是板块逻辑没坏下的回踩，还是趋势走弱；今天这个冲高，是主升确认，还是脱离板块的脉冲。你真正要练的不是操作次数，而是识别哪类日子适合做、哪类坚决不动。
