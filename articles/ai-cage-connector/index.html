Cage：AI互联升级里容易被忽略的小环节

2026-06-04 · 产业思考 · 光通信

AI服务器硬件链条里，市场最容易先关注GPU、HBM、光模块、交换机、PCB、CCL，但还有一个更细的小环节值得留意：cage。

这里的cage不是普通意义上的"笼子"，而是高速接口里的金属插槽 / 屏蔽笼 / 模块承载框架。简单说：光模块、铜缆模块插进去的那个金属框架，就是cage。

一、Cage是什么？

功能作用
机械固定稳定固定光模块或铜缆模块
电磁屏蔽减少高速信号干扰
散热帮助模块把热量导出去
插拔承载保证接口多次插拔后的稳定性
结构保护保护高速接口和连接器

二、为什么AI服务器会带动cage？

AI集群扩大
→ 高速互联需求增加
→ 铜缆/光模块数量增加
→ 高速接口数量增加
→ cage需求增加

三、铜缆和光模块都离不开cage

连接方式优点缺点主要场景
铜缆成本低、功耗低、延迟低距离短、速率受限柜内scale-up
光模块距离远、带宽高成本高、功耗高、散热压力大柜外scale-out

铜互联和光互联并不是互斥地压制cage，反而都会增加高速cage的使用场景。

四、1.6T之后，cage价值量可能提升

从400G到800G再到1.6T，接口速率提升的同时功耗和散热压力也在上升。这会推动cage从普通结构件升级为更高价值量的散热结构件：

普通cage → 加强散热cage → 带散热片cage → 液冷cage

投资逻辑不只是"数量增加"，还包括单个cage价值量提升。

五、投资链条位置

AI算力需求
→ GPU/ASIC放量
→ 交换机、网卡、光模块、铜缆需求增加
→ 高速接口密度提升
→ cage、连接器、散热结构件需求提升

它不是第一层核心瓶颈，而是高速互联放量后，向连接器和精密结构件扩散的二阶机会。

六、验证框架

验证点关键问题
产品真实性是否真的有高速cage/高速连接器/光模块结构件
客户认证是否进入NVIDIA、交换机厂、光模块厂、服务器厂供应链
收入占比这块业务占比是否足够高
技术门槛是否只是普通冲压件，还是高频高速、高散热结构件
放量节奏800G/1.6T/液冷cage是否进入批量阶段
毛利率变化产品升级是否带来毛利率提升

七、核心结论

AI集群扩大
→ 高速互联升级
→ 铜缆和光模块数量增加
→ 高速接口密度提升
→ cage需求增加
→ 1.6T功耗提升
→ 普通cage向散热cage/液冷cage升级
→ 连接器与精密结构件公司获得二阶扩散机会

这条线优先级低于GPU、HBM、光模块、PCB/CCL，但在A股交易中，可能因为"小环节+高弹性+AI互联扩散"而被资金阶段性挖掘。适合放在AI互联二阶扩散 / 高速连接器 / 精密结构件 / 液冷散热升级框架里跟踪。
