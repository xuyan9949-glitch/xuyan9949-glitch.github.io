A股炒作传导逻辑框架

2026-05-29 · A股 · 框架

A股短期奖励预期差和稀缺性，中期奖励业绩兑现，长期奖励现金流和壁垒。

一、板块炒作的典型传导顺序

1. 第一层：龙一

最正宗、最容易被市场一句话理解的核心标的。业务纯度高，市场辨识度强，资金第一时间想到它，公募、私募、游资共同认可。成交额迅速放大，走势最强，调整时也最抗跌。

判断标准：不是谁估值最低，而是谁最能代表这条主线。

例子：AI PCB（沪电股份、胜宏科技）、光模块（中际旭创、新易盛）、CPO/光器件（天孚通信、太辰光）、半导体设备（北方华创、中微公司）、存储（兆易创新、佰维存储、江波龙）。

2. 第二层：龙二 / 强趋势补充

龙一涨高后，资金寻找同赛道里逻辑相近、涨幅相对低、业绩也能兑现、市值更小或弹性更高的标的。龙一太贵了但板块逻辑还没结束，所以找龙二。

3. 第三层：细分环节扩散

主线确认后，市场从核心公司扩散到产业链细分环节。例如AI PCB扩散到CCL、电子布、铜箔、钻针耗材、设备等；光通信扩散到EML激光器、InP衬底、DSP、光器件、光纤光缆等。市场开始找"谁是瓶颈，谁有涨价能力"。

4. 第四层：低位滞涨补涨

当龙一、龙二、细分龙头都涨过后，资金寻找低位、没怎么涨、有一点相关性的标的。基本面通常没那么硬，涨得快回撤也快。逻辑可能是真的，但股价炒的是"轮到它了"，不是"它最受益"。

5. 第五层：参股 / 蹭概念 / 影子股

行情后段常见现象：参股某核心公司、间接供应、子公司有相关业务。判断标准：真实订单 > 客户认证 > 收入占比提升 > 产能扩张 > 参股（偏主题）> 互动平台概念（偏情绪）> 小作文（点火工具）。

6. 第六层：退潮阶段

后排乱炒时行情可能进入尾声。信号：龙头高位放量滞涨、利好不涨、后排补涨越来越弱、小作文密集、龙虎榜游资博弈加重、强票补跌、成交额放大但价格推不动。

二、一句话版本

龙一 → 龙二 → 细分瓶颈 → 低位补涨 → 参股蹭概念 → 退潮。
更细：纯度最高的先涨，逻辑最硬的走趋势，位置最低的补涨，最虚的最后乱飞。

三、资金为什么这么传导？

公募买业绩龙头，私募买预期差，游资买辨识度，量化追成交额，散户追扩散概念。不同资金的关注点不同，所以一个板块起来不是所有资金同时买一个逻辑。

四、判断行情阶段

阶段现象含义
启动期龙头先涨，后排没动主线刚被确认
主升期龙头趋势加速，龙二跟上资金认可度提高
扩散期上游、材料、设备、耗材都开始涨市场开始挖产业链
补涨期低位小票、二三线标的乱动情绪扩散
末期参股、互动平台、小作文票大涨退潮风险升高
退潮期龙头滞涨，后排先跌，利好不涨需要防守

五、核心规则

  1. 先炒预期差，不是先炒估值 — 市场原来以为它不行，现在发现它可能行
  2. 纯度比大而全更重要 — 一句话能讲清楚的公司容易获得溢价
  3. 先买瓶颈，再买龙头，再买扩散 — 瓶颈 > 直接龙头 > 设备材料 > 二线补涨 > 参股映射 > 蹭概念
  4. 题材真实，不代表买点合理 — 高位利好要防止成为兑现点
  5. 财报最终负责审判 — 小作文点火，财报决定走多远

六、主流产业链传导路径

AI PCB / CCL：PCB龙头 → CCL → 电子布/PTFE/铜箔 → 钻针耗材/设备 → 低位补涨/蹭概念

光模块 / CPO：光模块龙头 → 光芯片/EML/InP → 电芯片DSP/TIA/Driver → 光器件/材料 → CPO设备/测试 → 低位补涨

存储 / HBM：HBM/DRAM龙头 → 设备 → 材料 → 封测 → 国产替代 → 参股映射

七、最终口诀

第一，看主线是不是够大。
第二，看龙一是谁。
第三，看资金扩散到哪一层。
第四，看当前买的是瓶颈、业绩、还是纯情绪。
第五，看财报能不能接住股价。
第六，后排乱飞时，不要把情绪票当成长线逻辑。
