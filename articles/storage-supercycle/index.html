存储超级周期跟踪：财报时间线、业绩预期与美光财报前仓位策略

2026-06-19 · 美股 · 存储

更新时间：2026年6月19日

一、事件摘要

当前存储行业仍处于AI需求、产能结构调整与供给约束共同推动的强上行周期。TrendForce预计，2026年第二季度传统DRAM合同价环比上涨58%—63%，NAND Flash合同价上涨70%—75%；与此同时，厂商继续将产能优先配置给服务器DRAM、HBM和企业级SSD，导致消费级及传统产品供给进一步收紧。PC DRAM价格上行趋势预计还会延续至三、四季度。

因此，接下来主要存储公司的财报大概率都不会差。市场真正交易的已经不是"业绩是否增长"，而是：

  1. 增长幅度能否超过已经大幅上调的一致预期；
  2. 管理层能否继续给出更强的下一季度指引；
  3. 当前异常高的毛利率能否维持；
  4. 资本开支是否开始威胁2027—2028年的供需格局；
  5. AI存储需求能否从HBM继续扩散至服务器DRAM、企业级SSD与近线HDD。

二、核心投资判断

这轮存储周期与传统消费电子补库存周期不同。其主要驱动力不是PC和手机复苏，而是AI服务器对HBM、DDR5、SOCAMM、企业级SSD和数据归档容量的系统性提升。

其中：

  • DRAM/HBM的确定性最高：AI服务器提高单机内存价值量，同时HBM挤占先进制程产能，反过来强化普通DRAM短缺。
  • NAND的利润弹性最大：企业级SSD需求和前期供给纪律共同推动价格、毛利率和利润快速扩张。
  • HDD的爆发力相对较弱，但持续性可能更好：AI产生的大量冷数据和长期数据仍需依赖低成本大容量存储。

当前行业没有明显见顶证据，但股票交易已经从"景气反转"进入"高预期兑现"阶段。越是业绩弹性大的公司，财报后出现"数字很好、股价却下跌"的概率反而越高。

四、主要公司的业绩预期

1. 美光 MU：全球存储板块最重要的定调财报

美光上一季度给出的FY2026 Q3指引为：

项目公司指引
营收335亿美元±7.5亿美元
非GAAP毛利率约81%
非GAAP EPS19.15美元±0.40美元

这已经是一份非常激进的指引，意味着本次财报不能只做到"增长很好"，而必须继续体现价格、产品组合和利润率的超强趋势。

市场重点不会只看当季EPS，而会集中观察：

  • 下一季度营收指引是否继续明显上移；
  • DRAM、NAND价格上涨能否持续到下半年；
  • HBM与服务器DRAM出货是否继续加速；
  • 企业级SSD能否成为第二增长曲线；
  • 毛利率能否维持在极高水平；
  • 资本开支增加是否超出市场容忍范围。

判断：业绩确定性高，但预期差风险也很高。 美光大概率会交出一份优秀财报，但优秀并不等于股价一定上涨，市场需要的是继续"beat and raise"。

2. SK海力士：基本面质量最高

SK海力士2026年第一季度营收达到52.58万亿韩元，营业利润37.61万亿韩元，创历史新高，主要受高附加值AI存储产品推动。

海力士的核心优势在于：

  • HBM3E领先地位较稳固；
  • HBM4技术和客户关系延续性较强；
  • 普通DRAM涨价形成第二利润来源；
  • Solidigm受益于企业级SSD需求；
  • 产品组合和利润率优于单纯依赖传统存储涨价的厂商。

UBS此前预计，SK海力士在英伟达Rubin平台HBM4市场中的份额可能达到约70%，说明其HBM领先优势有望跨代延续。

判断：存储行业中基本面质量和确定性最高，但市场预期同样已经很高。 财报若只是延续强劲，而没有进一步强化HBM4份额和长期供需，股价反应未必与利润增速成正比。

3. 三星电子：传统DRAM利润弹性最大之一

三星2026年第一季度营收133.9万亿韩元，营业利润57.2万亿韩元，均创季度纪录；其中DS半导体部门营收81.7万亿韩元，营业利润53.7万亿韩元，几乎贡献了集团全部利润增量。三星称存储业务受益于AI需求、有限供给和ASP上涨，并已开始销售HBM4及SOCAMM2产品。

三星的优势是：

  • DRAM和NAND体量最大；
  • 对传统存储涨价的绝对利润弹性极强；
  • 产品覆盖HBM、服务器DRAM、消费DRAM、NAND和企业级SSD；
  • 若HBM4竞争力恢复，估值还存在进一步重估空间。

但三星并非纯存储公司，手机、显示、晶圆代工和消费电子业务可能抵消部分存储利润。尤其是在存储价格快速上涨时，三星自身的终端业务也会面临成本压力。

判断：三星是传统DRAM超级周期的重要受益者，但股价要进一步重估，不能只依赖涨价，还需要证明HBM份额持续恢复。

4. 闪迪 SNDK：NAND利润弹性最强，但交易门槛最高

闪迪FY2026 Q3营收59.5亿美元，环比增长97%；非GAAP毛利率78.4%，非GAAP EPS为23.41美元，数据中心收入环比增长233%。公司对下一季度给出的指引为：

项目公司指引
营收77.5亿—82.5亿美元
非GAAP毛利率79%—81%
非GAAP EPS30—33美元

公司同时签署多份长期客户协议，希望通过多年期采购承诺降低NAND业务传统的高波动属性。

闪迪的核心逻辑已经从传统消费闪存转向：

  • 云端与数据中心SSD；
  • 高价值客户占比提升；
  • NAND ASP快速上涨；
  • 与客户签署长期供货及资金承诺；
  • 资产负债表和现金流改善。

判断：利润爆发力极强，但也是最容易出现"财报很好、股价不涨"的公司之一。 当毛利率接近80%时，市场会开始质疑这一盈利水平的可持续性。

5. 铠侠 Kioxia：NAND制造端最纯的价格弹性

铠侠是全球主要NAND制造商之一，与闪迪共享日本合资产能，因此两家公司必须结合观察：

  • 铠侠更能反映晶圆制造、良率、稼动率和成本；
  • 闪迪更能反映销售渠道、客户结构和数据中心SSD溢价。

铠侠已于2026年5月15日发布上一财年结果，并于6月2日举行Investor Day；其IR日历显示，一季度财报通常在8月公布。

在NAND合同价预计二季度上涨70%—75%的背景下，铠侠仍是利润弹性最大的纯周期标的之一。

判断：盈利弹性极高，但风险也集中在NAND价格增速放缓、客户需求破坏和未来产能恢复。

6. 希捷 STX：HDD中利润率和技术弹性更强

希捷FY2026 Q3实现营收31.12亿美元，非GAAP毛利率47%，非GAAP EPS 4.10美元，自由现金流9.53亿美元。公司对下一季度指引为营收34.5亿美元±1亿美元、非GAAP EPS 5.00美元±0.20美元。

希捷的主要催化包括：

  • HAMR/Mozaic产品爬坡；
  • 单盘容量持续提升；
  • 云厂商近线HDD需求；
  • 毛利率和自由现金流改善；
  • 单位EB资本效率提升。

判断：业绩爆发力不如NAND，但利润质量和持续性更好。

7. 西部数据 WDC：HDD周期与现金流逻辑

西部数据在分拆闪迪后，已经主要是一家HDD公司。FY2026 Q3营收33.37亿美元，同比增长45%；非GAAP毛利率50.5%，非GAAP EPS 2.72美元，自由现金流9.78亿美元。公司对下一季度指引为营收36.5亿美元±1亿美元、毛利率51%—52%、非GAAP EPS 3.25美元±0.15美元。

其核心投资逻辑是：

  • AI训练、推理和Agent应用创造大量长期数据；
  • HDD仍是大规模冷数据存储的最低成本方案；
  • 行业供给纪律较过去周期明显改善；
  • 毛利率、现金流和股东回报持续提升。

判断：弹性略低于希捷，但现金流稳定性和股东回报更突出。

五、公司预期排序

按基本面确定性

SK海力士 > 美光 ≈ 三星 > 闪迪 ≈ 铠侠 > 希捷 > 西部数据

按利润弹性

闪迪 ≈ 铠侠 > SK海力士 > 美光 > 三星 > 希捷 > 西部数据

按"好业绩但股价下跌"的风险

闪迪 > 铠侠 > 美光 > 三星 > SK海力士 > 希捷 > 西部数据

当前市场已经进入"必须持续超预期并上调指引"的阶段。业绩数字越夸张，反而越要警惕预期已经提前透支。

六、当前存储持仓穿透分析

当前实际持仓修正为：

标的资金仓位
Roundhill Memory ETF（DRAM）16%
美光5%
两倍做多三星8%
韩国大盘指数6%
名义资金占比35%

DRAM ETF披露的主要权重为：美光28.17%、SK海力士25.51%、三星18.60%、铠侠7.95%。该权重为基金页面披露时点数据，之后可能动态变化。

按这一权重穿透，16%的DRAM ETF约对应：

公司DRAM ETF间接仓位
美光约4.51%
SK海力士约4.08%
三星约2.98%
铠侠约1.27%

加上5%的美光正股，你对美光的直接加间接仓位约为：

5% + 4.51% = 9.51%

也就是说，美光财报对你组合的影响并不只是5%，而是接近9.5%的直接和间接暴露。

与此同时，8%的两倍做多三星产品，对应约16%的三星单日方向敞口。再加上DRAM ETF中的三星，以及韩国指数中潜在的三星和SK海力士权重，你实际上通过多个产品重复押注同一个存储因子。

若韩国指数中三星和海力士合计权重约为40%—45%，6%的韩国指数还会额外贡献约2.4%—2.7%的存储敞口。由于未明确具体指数或ETF代码，这部分只能作区间估算。

因此：

  • 名义资金仓位：35%
  • 按三星两倍杠杆和韩国指数穿透后的有效存储方向敞口：约39%—40%

这里的"有效敞口"指方向敏感度，并不等同于实际投入资金。

核心问题

当前组合不是简单持有四个不同资产，而是：

  • DRAM ETF持有美光、海力士、三星、铠侠；
  • 另有5%美光正股；
  • 另有8%两倍三星；
  • 韩国指数再次包含三星和海力士。

因此，组合的主要风险是：

高相关性 + 重复持仓 + 两倍杠杆 + 财报隔夜跳空。

七、美光财报前的仓位策略

核心结论

在DRAM仓位修正为16%后，之前"不动观察"的方案不再合适。

美光财报前不建议加仓，也不建议完全清仓；应主动降低重复杠杆和组合级事件风险。

建议调整为：

标的当前仓位财报前建议区间
DRAM ETF16%10%—12%
美光5%保留5%
两倍做多三星8%降至4%—5%
韩国大盘指数6%保留6%

更明确的基准版本是：

  • DRAM ETF：11%
  • 美光：5%
  • 两倍三星：4%
  • 韩国指数：6%

调整后名义仓位从35%降至26%，释放约9%现金；有效存储方向敞口大约降至26%—27%。这仍然是明确重仓看多存储，但不再让单次美光财报演变成组合级风险。

八、为什么主要减DRAM ETF和三星两倍，而不是美光

1. 美光5%应保留核心仓

虽然美光是本次财报的直接风险源，但5%正股仓本身并不算过重。即使财报后下跌15%，对组合的直接损失约为0.75个百分点。

而且，美光是全球存储周期最重要的领先财报之一。如果财报强于预期并继续上调指引，完全减掉美光会削弱组合最直接的受益敞口。

2. DRAM ETF已经隐含较多美光

16%的DRAM ETF中约有4.5%美光，因此你实际对美光的暴露已经接近9.5%。把DRAM从16%降到11%，不会破坏存储主线，但能显著减少财报相关性。

3. 三星两倍是组合中风险最高的一层

美光财报在美股盘后公布，次日韩国市场可能直接跳空反应。两倍三星会放大这种隔夜冲击，同时每日重置机制还会带来路径依赖和波动损耗。

更重要的是，三星已经同时存在于：

  • DRAM ETF；
  • 两倍三星产品；
  • 韩国大盘指数。

因此，减三星两倍并不等于放弃三星，而是剔除重复杠杆。

九、具体执行方案

情形一：财报前存储板块继续上涨

若6月22日至24日，美光和存储板块继续明显上涨：

  • DRAM ETF从16%减至10%—11%；
  • 两倍三星从8%减至4%；
  • 美光5%不动；
  • 韩国指数6%不动。

这是最应严格执行减仓的情形，因为股价越接近财报前高位，预期差风险越大。

情形二：财报前先回撤5%—8%

若存储板块在财报前已经明显回撤：

  • DRAM ETF只减至12%；
  • 两倍三星减至5%；
  • 美光和韩国指数不动。

不应在连续下跌后机械减到最低仓位，但仍不建议逆势加仓。

情形三：财报前出现行业级利空

若出现价格数据转弱、客户削减订单、资本开支大幅增加或AI服务器需求下修：

  • DRAM ETF降至10%以下；
  • 两倍三星降至3%—4%；
  • 美光保留小核心仓；
  • 等待财报确认后再评估。

十、财报后的三种情景

情景一：强超预期并大幅上调指引

特征：

  • 当季营收接近或超过公司指引上沿；
  • 下一季度营收明显高于市场预期；
  • 毛利率继续维持高位；
  • HBM、服务器DRAM和企业级SSD需求继续强化；
  • 资本开支虽增加，但没有出现失控式扩张。

操作：

  • 不追盘后价格；
  • 等待正式开盘后30—60分钟；
  • 若高开缺口守住，优先加回2%—3%的DRAM ETF；
  • 不优先加三星两倍，先观察韩国市场自身确认。

情景二：业绩很好，但指引只符合高预期

这是最容易出现"sell the news"的情形。

操作：

  • 不因EPS数字夸张就立即抄底；
  • 观察首日能否收回盘中跌幅；
  • 等待第二天或回踩关键均线后再补仓；
  • 优先补DRAM ETF，而不是两倍三星。

情景三：指引低于预期或资本开支明显超预期

特征：

  • 下一季度收入指引未继续上调；
  • 毛利率开始回落；
  • HBM或服务器需求低于预期；
  • 资本开支再次大幅提高；
  • 管理层提到客户库存、价格阻力或需求提前透支。

操作：

  • 不急于接回减掉的仓位；
  • 继续降低两倍三星；
  • 保留美光小核心仓；
  • 等三星和海力士财报进行二次验证。

十一、主要风险

1. 预期透支

当前卖方和市场已经大幅提高存储盈利预期，最大的短期风险不是行业突然转差，而是增长速度无法继续超过市场想象。

2. 资本开支扩张

美光、三星、海力士和铠侠都在扩张先进产能。新产能短期无法快速释放，但市场可能提前交易2027—2028年的供给增加。

3. 价格上涨导致需求破坏

存储涨价最终会抬高手机、PC、服务器和消费电子成本。若涨价过快，下游客户可能削减配置、延迟采购或加速库存消化。

4. NAND盈利不可线性外推

闪迪和铠侠当前利润率处于极端高位，不能简单把单季盈利年化。NAND价格一旦从快速上涨转为平稳，利润增速会明显下降。

5. 杠杆产品路径依赖

两倍产品追踪单日收益，不等于长期累计收益的简单两倍。高波动、跳空和反复震荡都会产生损耗。

6. 重复持仓被低估

表面上持有DRAM、美光、三星和韩国指数，实际上主要押注同一个存储周期。仓位必须按因子穿透管理，而不能只看产品数量。

十二、结论

当前存储行业基本面仍然强劲，DRAM、HBM、NAND、企业级SSD与近线HDD均处于景气上行阶段。海力士的基本面质量最高，美光是全球存储财报最重要的定调者，三星是传统DRAM涨价的重要受益者，闪迪和铠侠利润弹性最大，希捷和西部数据则提供更稳定的HDD和现金流逻辑。

但当前组合的主要问题已经不是方向判断，而是仓位结构：

  • DRAM ETF 16%；
  • 美光5%；
  • 两倍三星8%；
  • 韩国指数6%；
  • 名义仓位35%；
  • 有效存储方向敞口约39%—40%。

在这种情况下，美光财报前继续加仓不合理，完全不动也偏冒险。

建议的财报前基准方案是：DRAM降至11%，美光保留5%，两倍三星降至4%，韩国指数保留6%。

这样可以把名义仓位降至26%，保留存储超级周期的核心收益，同时降低财报隔夜风险、重复暴露和两倍杠杆带来的组合冲击。财报后再根据下一季度指引、毛利率、资本开支和股价承接决定是否重新加仓。
