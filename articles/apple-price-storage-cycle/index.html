苹果涨价是存储周期最后一根稻草？——对"周期见顶论"的七层次拆解

2026-06-27 · 产业思考 · 存储

核心结论

"苹果涨价是存储周期最后一根稻草"这个标题，目前证据远远不够。

它把三个不同层面混在了一起：苹果硬件成本上升、消费电子销量可能承压、整个存储行业景气立即见顶。

第一点已经发生，第二点有可能发生，第三点尚未得到验证。苹果涨价既可以被解释为需求破坏的早期信号，也可以被解释为：连全球供应链议价能力最强的苹果，都暂时无法压住存储厂商的价格。

一、以前美光真的被苹果"压榨"过吗？

苹果长期拥有很强的采购议价权，但没有充分公开证据证明，美光历史上的巨额亏损主要是苹果压价造成的。

苹果、微软、戴尔、惠普等大型OEM通常会采用多供应商认证、年度或季度议价、竞价采购、锁量换价等方式降低采购成本。在供给宽松时期，客户可以在三星、SK海力士、美光之间切换订单，大客户确实能压低合同价格。

但美光历史最惨的时期，财务报告给出的原因非常明确：全球性产能过剩、DRAM和NAND价格崩塌，以及2008年金融危机造成的需求下滑，而不是某一个客户压价。

2007—2009年，美光DRAM每比特平均售价分别下降23%、51%和52%；NAND分别下降56%、67%和56%。美光在2007、2008、2009财年分别净亏损3.2亿美元、16亿美元和18亿美元，存储业务毛利率在2008年为负5%，2009年进一步降至负12%。

这里的关键是：美光不是因为卖给苹果太便宜而亏损，而是当时整个市场价格跌得比制造成本下降得更快。苹果等大客户只是在供过于求时充分利用了买方市场，并不是周期崩溃的根本制造者。

美光现在披露，前十大客户贡献了超过一半的收入，说明大客户集中度和议价能力始终是风险因素；但公司不公开单个客户的完整采购价格和利润，因此"苹果长期把美光压到破产边缘"更多是一种供应链叙事，而不是可以被财报证实的结论。

二、美光以前是否差点破产？

美光在2009财年末持有约14.85亿美元现金及短期投资，但当年净亏损18亿美元。公司在年报中明确警告，由于存储行业严重衰退、信贷市场恶化，融资可能变得困难；不得不大幅压缩资本开支、削减成本，并考虑更多融资方案。

更专业的判断是：美光当时处于严重财务压力和产业淘汰风险中，但并没有进入正式破产程序。

真正被上一轮存储周期淘汰的包括：德国Qimonda于2009年申请破产；日本Elpida于2012年申请破产保护（负债约4,480亿日元），后来被美光收购；SK海力士在本世纪初也曾因债务问题接近崩溃，后来经过重组和被SK集团收购才重新崛起。

所以你听到的"存储厂差点破产"并不是夸张，但具体到美光，更准确的表述是：美光经历过足以淘汰同行的极端行业低谷，但它自己挺了过来，并趁机收购了Elpida，完成了行业集中度提升。

三、以前存储周期是怎么形成的？

传统存储周期本质上由四件事决定：需求、产能、技术节点和库存。

存储厂的固定成本极高，晶圆厂一旦建成，就倾向于持续生产。与此同时，每次制程升级、晶圆尺寸升级或层数增加，都会让每片晶圆能够生产更多比特。问题在于，新增产能从决策到投产需要数年，而需求变化却可以在几个月内发生。

典型过程：景气上行价格上涨 → 厂商盈利暴增 → 扩大资本开支 → 新产能和先进制程释放 → 供给增速超过需求 → 库存积压价格暴跌 → 厂商亏损减产削减资本开支 → 库存消化 → 下一轮涨价。

2000—2002年：PC周期崩塌。美光每比特平均售价在2001年下降60%，2002年又下降53%。

2007—2009年：产能过剩叠加金融危机。300毫米晶圆和制程升级带来巨大比特供给，随后金融危机压低PC和消费电子需求。美光连续三年亏损，Qimonda破产。

2016—2018年：从低谷到超级盈利。2016年PC需求疲弱，美光DRAM平均售价下降35%。随后云计算、服务器和智能手机容量升级带来需求恢复，供给了受限，2017年和2018年DRAM价格分别上涨19%和37%。

2019年：库存修正。2018年高价刺激供应增加，云客户开始消化库存。2019年美光DRAM平均售价下降30%，NAND下降44%。

2022—2023年：疫情需求透支后的崩塌。PC、手机、服务器提前采购，随后需求降温。2023财年美光DRAM平均售价下降接近50%，NAND下降超过50%，毛利率从2022年的45%降至负9%。

这就是传统存储行业最残酷的地方：比特需求长期增长，并不等于收入和利润长期稳定增长。只要比特供给增长得更快，价格仍然会崩。

四、现在AI是否改变了存储的周期属性？

AI明显改善了存储行业的结构，但没有消灭周期。

现在与过去相比，发生了四个根本变化：

第一，存储从"容量元件"变成了"算力瓶颈"。AI时代，HBM和高容量DDR5直接决定GPU能否被充分利用。带宽不足、容量不足，昂贵的GPU就会等待数据。美光在2023年估算，AI服务器的DRAM容量约为普通服务器的6—8倍，NAND容量约为3倍。HBM不是普通意义上的可选配件，而更像AI加速器系统的关键子系统。

第二，HBM减少了传统DRAM的有效供给。HBM占用更多DRAM晶圆、先进制程和复杂封装资源。即便行业晶圆投入不变，当更多产能转向HBM，普通DDR5、LPDDR等产品的有效供给也会受到挤压。

第三，合同模式正在变化。这是现在和过去最大的差别之一。美光在2026年签署的战略客户协议包含多年期锁量、take-or-pay、价格下限和部分价格上限。公司表示，即便按照部分合同的最低价格销售，毛利率仍可能高于过去任何一个周期的峰值季度。这意味着一部分模式从"客户随时砍单，存储厂承担全部风险"变成了"客户提前锁量、支付保证金，甚至承担部分需求风险"。

第四，数据中心已经成为美光核心业务。2025财年，美光数据中心业务占收入约56%，业务毛利率约52%。美光已经不再主要依靠PC和手机周期。

但我要强调：存储仍然不是无周期的消费品。以下风险依然存在：云厂商资本开支可能阶段性停顿；AI投资回报率如果低于预期，服务器订单可能推迟；三星、海力士、美光最终都会扩产；HBM良率改善会释放更多有效供给；模型压缩、量化、内存池化、分层存储会降低单位计算对高端内存的需求；NAND比DRAM更容易出现供给过剩；PC和手机仍然存在库存周期。

现在更合适的定义不是"周期消失"，而是：存储从纯商品周期，进入了"结构性成长叠加供给周期"的阶段。HBM更接近高端设备和定制化基础设施，普通DRAM和NAND仍然保留较强的大宗商品属性。

五、未来机器人和数据中心的存储需求会不会爆量？

数据中心：确定性较高，当前是主要增量。美光预计2026年行业DRAM和NAND比特出货量均增长约20%，且增长受限于供给而非需求不足。HBM市场规模预计从2025年约350亿美元增长至2028年约1,000亿美元，复合增速约40%。数据中心需求来自三层：GPU旁边的HBM、CPU服务器中的DDR5/LPDDR/SOCAMM、数据存储所需的企业级SSD。Agentic AI还可能同时增加GPU机架、CPU控制平面和存储机架。

但数据中心不会永远按照当前斜率增长。任何基础设施建设都会经历：建设不足 → 加速投资 → 过度建设 → 利用率消化。AI数据中心也不会违反这个规律。

机器人：长期重要，但目前不是主导变量。机器人、自动驾驶和工业边缘AI确实需要更多DRAM、NAND和高可靠存储。但机器人是五到十年的第二增长曲线，不是当前存储超级周期的主要支撑。目前机器人出货规模远小于手机、PC和服务器，单台机器人的存储价值量也通常远低于一套AI服务器机架。

六、如果苹果、微软因为存储涨价而受损，是否会和存储厂一损俱损？

短期不一定，中长期可能。

核心公式：存储需求 = 终端销量 × 单机存储容量。假设电脑销量下降，但每台电脑的内存从16GB升级至32GB，存储总比特需求可能仍然增长。

同时：存储厂收入 = 出货比特数 × 每比特价格。所以即使苹果或微软销量下降，只要存储价格涨幅和单机容量增幅足够大，美光收入仍可能上升。这种利益转移在短期完全可能发生。当产能紧张时，如果苹果少买一些，存储厂可能把产能卖给英伟达、云厂商或服务器客户，未必形成库存。

但到了中长期，如果出现以下情况，就会真正"一损俱损"：

  • PC、手机、游戏机销量持续大幅下降；
  • 客户主动降低内存和存储配置；
  • 云厂商AI资本开支减速；
  • 存储厂新产能大量投产；
  • 客户库存重新累积；
  • 现货价格和合同价格同时下跌。

大客户也不会被动承受。它们会采取长约锁价、增加供应商、降低低端产品配置、优化软件和模型、使用更便宜的存储层级、推迟部分产品发布、要求存储厂共同承担价格风险等措施。

美光当前推出带价格上下限和锁量条款的多年合同，本质上正是在解决这种矛盾：既防止客户在低谷随意砍单，也防止供应商在极端短缺时无限涨价。

七、苹果涨价到底是不是周期见顶信号？

它是一个值得监控的信号，但不是结论。

苹果涨价说明：存储价格已经上涨到无法完全内部吸收；存储厂当前定价权非常强；涨价开始从产业链上游传导到消费者；需求破坏风险开始上升。

但真正的周期顶部，不是苹果宣布涨价，而是后面出现：

  • 苹果、戴尔、微软降低存储采购量；
  • 手机、PC销量预测连续下调；
  • 客户库存开始增加；
  • 存储现货价格先于合同价下跌；
  • 供应商交货期缩短；
  • HBM不再售罄；
  • 云厂商推迟AI服务器订单；
  • 存储厂资本开支和产量增长超过需求。

在这些数据出现之前，"最后一根稻草"只是一个情绪化标题。

最终判断：苹果涨价不是存储逻辑被证伪，而是存储定价权强到开始引发下游反作用。这意味着风险确实比几个月前更高，但它更接近景气从无争议阶段进入博弈阶段，而不是已经确认进入下行周期。

你真正需要警惕的不是媒体说"苹果不高兴"，而是苹果、微软、戴尔和云厂商开始用实际订单告诉存储厂：我们不再需要这么多比特了。在那之前，苹果涨价本身反而证明了一个事实：当前存储供给仍然稀缺，苹果暂时也没有足够力量迫使供应商降价。
