甲骨文FY26Q4财报：机构视角笔记

2026-06-11 · 美股 · 财报分析

一、机构一句话判断

这份财报的核心不是"好不好"，而是：需求端极强，订单端极强，但资本开支、融资、毛利率和自由现金流压力也同步放大。

维度机构判断
基本面需求强，OCI和AI基建订单继续验证
财务质量有压力，FCF深度为负，融资需求上升
估值逻辑从"高毛利软件公司"向"AI云基础设施重资产公司"切换
股价反应跌的不是需求，是CapEx/债务/股权稀释/ROIC不确定性

三、最关键的指标：RPO

RPO = Remaining Performance Obligations，剩余履约义务。可以理解为已经签下、未来会逐步确认的合同收入。

甲骨文本季度 RPO 达到 6380亿美元，同比+363%，环比从5530亿美元增加850亿美元。这不是普通软件公司级别的订单，而是AI云基础设施订单级别的爆发。官方还披露，大型AI合同里，客户预付GPU或客户自带GPU部分合计已经达到 750亿美元，这能部分降低甲骨文自己垫资买硬件的压力。

机构问题判断
订单真实不真实？真实，RPO和客户预付款说明需求不是PPT
订单能不能变收入？能，但取决于数据中心交付、GPU、电力、网络、冷却
订单质量高不高？需要观察毛利率和现金回收节奏
是否全部利好？不是。订单越大，CapEx和融资压力越大

管理层在电话会上说，RPO中12%预计未来12个月确认收入，34%预计在第13-36个月确认。换算即未来12个月约765.6亿美元，之后两年约2169亿美元有望确认。

四、为什么财报强，股价还跌？

机构看财报不是看"营收和EPS有没有beat"这么简单，而是看：上修收入的同时，是否也上修了资本开支、债务、摊薄和利润率压力。

Reuters披露，甲骨文FY26资本开支达到556.6亿美元，高于此前500亿美元目标；FY27 CapEx最高可能到950亿美元，其中约700亿美元为甲骨文自身支出，另有200-250亿美元预计由客户偿还。甲骨文还预计FY27通过债务和股权融资约400亿美元。

市场的逻辑链条：

  1. 需求强 → 应该涨
  2. 需求太强 → 必须疯狂建数据中心 → CapEx暴增
  3. CapEx暴增 → FCF转负、债务上升、可能股权稀释
  4. 估值从软件公司变成AI基建公司 → 估值倍数下修

这就是机构砸盘的真正原因。

五、EPS beat的质量要打折

表面上Q4 Non-GAAP EPS是2.11美元，同比+24%。但官方脚注说明，这里面包含一次性投资收益；剔除该收益后，Q4 Non-GAAP EPS是2.03美元，同比+20%。FY26 Non-GAAP EPS表面是7.63美元，但剔除一次性收益后是6.83美元。

表面数据机构调整后看法
EPS 2.11，beat要剔除一次性投资收益
EPS同比+24%可比口径大约+20%
FY26 EPS 7.63可比口径6.83更重要
FY27 EPS指引8.05要看是否能覆盖融资和毛利率压力

六、毛利率：机构最敏感的隐性问题

CFO在电话会上说，FY26全年毛利率下降约5个百分点，主要因为基础设施业务扩张和数据中心建设影响。甲骨文现在遇到的是典型AI云转型矛盾：

原业务新业务
数据库/软件订阅AI云基础设施
高毛利较低毛利、重资产
低CapEx高CapEx
FCF强FCF短期承压
软件估值基建估值

七、管理层想讲的故事

管理层想让市场相信三件事：

第一，OCI不是短期爆发，而是长期万亿美元级市场。 电话会上管理层称，AI基础设施让原有云基础设施市场显得很小，目标利润率框架为30%-40%。

第二，客户愿意提前出钱，说明订单质量高。 本季度签下670亿美元AI基础设施合同，客户预付/自带硬件合计达750亿美元，管理层表示这类合同不会拉低利润率。

第三，交付速度正在加快。 FY26交付超过1.2GW给客户，FY27 Q1交付接近1GW，几乎相当于过去四个季度交付量总和；全球GPU利用率为97.5%。

十、交易笔记

对ORCL本身

我不会把它定义成"财报暴雷"。更准确是：财报强，但估值逻辑变复杂。

短线不适合简单追涨或抄底，原因是市场现在要重新定价三个东西：

  1. FY27 950亿美元CapEx是否继续上修
  2. 400亿美元融资是否造成债务压力和股权稀释
  3. OCI毛利率能否稳定在管理层说的30%-40%框架内

对AI主线

这份财报更像是一个产业链信号：Oracle不是AI需求变弱的证据，而是AI需求强到让市场开始担心融资和电力瓶颈的证据。

所以交易上不要把它理解成"AI结束"。更合理的理解是：

AI第一阶段交易"订单和收入高增长"；
AI第二阶段开始交易"谁能在高CapEx周期里真正赚到现金流"。

最终归纳：Oracle证明了AI云需求非常强，但也证明了AI基础设施不是轻资产故事；接下来市场不会只奖励订单，而会要求现金流、毛利率和资本回报兑现。
