AI产业术语全解：从CPO到TGV的23个核心概念

2026-06-02 · 产业思考

AI 产业链投资涉及大量技术术语，从光互连到先进封装，每个名词背后都对应一条供应链逻辑。本文按"它是什么 → 放在产业链哪里 → 为什么对投资重要"三个维度，梳理 23 个高频出现的核心概念。

一、光互连与交换

1. CPO：Co-Packaged Optics，共封装光学

它是什么？把光学引擎和交换芯片/ASIC 封装在一起，而非插在交换机前面板。核心是缩短光电转换之间的距离，降低功耗和延迟。

为什么需要？AI 集群数据交换量太大——传统架构电信号走远损耗大、前面板空间有限插不了更多光模块、高速信号完整性压力大。

投资含义：CPO 利好高功率 CW Laser、硅光芯片、FAU 光纤阵列、光引擎封装、光电测试设备、高端交换芯片生态。代表标的：LITE、COHR、AVGO、MRVL、VIAV、天孚通信、太辰光。

2. NPO：Near-Packaged Optics，近封装光学

它是什么？把光学引擎放到 GPU/ASIC 附近，但还没有像 CPO 那样完全集成进去。

对比NPOCPO
集成程度中等很高
距离芯片很近几乎贴在一起
量产难度较低较高
维护难度较低较高
适用阶段过渡/现实方案长期方案
模块厂参与度仍然较高可能下降

为什么重要？NPO 可能比 CPO 更早放量。AI 服务器内部 GPU 之间高速互联，铜线功耗和距离开始吃紧时，NPO 是把光互联推进到更靠近 GPU 位置的现实路径。可能是 2027 年最值得跟踪的光互联升级方向。

利好：光引擎、硅光、SerDes、Driver/TIA、FAU、高速封装测试、部分光模块厂。

3. OCS：Optical Circuit Switch，全光交换

它是什么？用光信号直接切换通信路径，不经过"光→电→光"的转换。

为什么 AI 集群需要？大模型训练中 GPU 集群数据流量巨大。传统电交换带来功耗、延迟、设备成本、网络拥塞。OCS 可以提高调度效率，尤其适合大规模集群。

投资含义：利好光交换设备、MEMS 光开关、硅光、轻相干模块、光纤连接器、网络系统厂商。Google 在 OCS 方向布局激进，值得单独跟踪。

二、光模块电芯片

4. DSP：Digital Signal Processor，数字信号处理芯片

它是什么？高速光模块里的"大脑"，负责修正高速信号失真、噪声、补偿和编码。速率越高，信号越容易失真，DSP 负责把信号修正回来。

功能：信号补偿、PAM4 编码解码、均衡抵消通道损耗、降低误码率、管理功耗和链路状态。

投资含义：800G/1.6T 光模块的重要电芯片。受益：Broadcom、Marvell、Credo、MaxLinear、Semtech、部分国产 DSP 厂商。但行业也在发展 LPO/LRO 等低功耗方案试图减少或简化 DSP。

5. TIA：Transimpedance Amplifier，跨阻放大器

它是什么？接收端电芯片，把 PD 产生的微弱电流信号放大成可处理的电压信号。光信号→PD 转电流→TIA 放大→DSP/CDR 处理。

投资含义：速率升级后，TIA 需要更高带宽、更低噪声、更低功耗、更好线性度。受益：MACOM、Broadcom、Marvell、Semtech、MaxLinear。

6. Driver：驱动芯片

它是什么？发射端电芯片，控制激光器或调制器如何发光。DSP/SerDes → Driver → EML 或调制器 → 光信号发出。

投资含义：与 TIA 一样，属于光模块关键电芯片。高速模块升级到 800G/1.6T 后，Driver 难度同步提升。

7. SerDes：Serializer/Deserializer，串并转换器

它是什么？高速数据接口芯片，在并行数据和串行高速数据之间互相转换。NPO/CPO 中 GPU、ASIC、光引擎之间都需要高速数据传输，SerDes 速度和功耗直接影响系统带宽和能效。

投资含义：SerDes 是 AI 芯片之间高速通信的底层能力。受益：Broadcom、Marvell、Credo、Astera Labs、Rambus。

三、光芯片与激光器

8. PD：Photodiode，光电二极管/探测器

它是什么？接收端器件，把光信号转换成电信号。如果说激光器是"发光的人"，PD 就是"看光的人"。

为什么 200G PD 会紧缺？800G/1.6T 光模块从 100G/lane 走向 200G/lane，要求 PD 响应更快、带宽更高、噪声更低、良率更难、和 TIA 配合要求更高。

投资含义：利好 InP 光芯片厂、高速接收端器件厂、光模块上游供应链。但注意：如果 NPO/CPO 中 PD 被集成进硅光芯片，传统独立 PD 的长期逻辑可能会弱化。

9. EML：Electro-Absorption Modulated Laser，电吸收调制激光器

它是什么？高速光模块中常用的发射端激光器，把电信号转换成高速光信号。在长距离和高速场景下表现好。

为什么重要？800G/1.6T 光模块放量 → 高速 EML 需求增加 → InP 光芯片、外延、衬底、封装测试受益。这是当前光通信紧缺环节之一。

受益：Lumentum、Coherent、源杰科技、长光华芯、AXT/云南锗业等 InP 衬底映射。

10. CW Laser：Continuous Wave Laser，连续波激光器

它是什么？持续稳定发光的激光器。不像 EML 自己完成高速调制，它提供稳定光源，由调制器把信息加载到光上。

为什么 CPO/硅光需要它？硅光方案中光源外置，由 CW Laser 提供持续光，再通过硅光芯片中的调制器处理信号。CPO/NPO/硅光越发展，高功率高可靠性 CW Laser 越重要。

一句话：EML 偏传统高速模块放量，CW Laser 偏 CPO/硅光/外部光源路线。

11. 硅光：Silicon Photonics

它是什么？用硅基半导体工艺制造光学器件，提高集成度、降低成本、提升规模化能力。

传统分立光器件硅光
器件分散集成度高
装配复杂更适合规模制造
成本较高长期有降本潜力
一致性较难控制工艺平台化更强

短板：硅本身不擅长发光，因此仍需要外部光源（如 CW Laser）。利好 CPO、NPO、光引擎、硅光代工、外部激光器、光电测试。

12. 轻相干：Light Coherent

它是什么？介于传统强度调制和完整相干通信之间的折中方案。保留部分相干优势，同时控制成本和功耗。

为什么可能重要？AI 集群规模扩大后，光纤数量、链路距离、网络调度复杂化。轻相干可减少光纤占用、提高链路效率。

偏中长期路线：利好相干 DSP、硅光、OCS、高端光模块、光通信测试。短期不如 800G/1.6T 模块直接。

13. FAU：Fiber Array Unit，光纤阵列单元

它是什么？把多根光纤精准排列并与光芯片连接的无源器件——光芯片和光纤之间的"精密接口"。

为什么重要？CPO/NPO/硅光方案中光纤数量多、排列密度高、耦合精度要求极高。FAU 对不准，光信号损耗变大。属于"不起眼但很关键"的环节。

受益：天孚通信、太辰光、其他精密光器件厂商。A 股常被当做 CPO/硅光/光引擎核心配套来炒。

四、电缆与互联架构

14. AEC：Active Electrical Cable，有源电缆

它是什么？带有主动电芯片的高速铜缆，比普通铜线传输更远、信号更稳定，但本质仍是电信号传输。

为什么 NPO 可能替代部分 AEC？AI 服务器内部 GPU 连接速率越来越高，铜缆面临距离限制、功耗提升、散热压力、信号完整性问题。NPO 把部分链路光化，可能替代一部分 AEC 市场。

投资含义：AEC 利好 Credo、Astera Labs 等互联芯片公司。若 NPO 渗透加快，部分 AEC 增量可能被光互联吃掉。

15. Scale-up 与 Scale-out

Scale-up（机柜内扩展）：把多个 GPU/ASIC 更紧密地连在一起，像一台更大的计算机。重点：低延迟、高带宽、近距离。NPO 主要服务 Scale-up。

Scale-out（集群间扩展）：把很多服务器/机柜连成一个大集群。重点：大规模、远距离、高吞吐。传统 800G/1.6T 光模块主要服务 Scale-out。

五、先进封装

16. Interposer：中介层

它是什么？先进封装中连接 GPU、HBM、芯片之间的中间层——就像一块高密度转接板。

为什么从硅到玻璃？传统 CoWoS 用硅中介层。AI GPU 越来越大、HBM 越来越多，封装面积变大。硅中介层在尺寸、成本、加工效率上遇到压力。玻璃 Interposer 可做更大尺寸、损耗低、平整度好、成本有潜力下降、适合面板级加工。

利好：特种玻璃、TGV 设备、研磨设备、涂胶设备、检测设备、先进封装厂。

17. TGV：Through Glass Via，玻璃通孔

它是什么？在玻璃里打垂直通孔实现上下层电连接。类比 TSV（硅通孔）：TSV 用在硅上，TGV 用在玻璃上。

为什么难？玻璃硬、脆、容易裂。要在玻璃上打大量微孔，还要保证孔壁质量、金属填充和可靠性。TGV 是玻璃基板/玻璃 Interposer 的关键工艺瓶颈。

18. CoWoS：Chip on Wafer on Substrate

它是什么？台积电先进封装技术，通过中介层把 GPU 和 HBM 放在同一个封装里。NVIDIA 高端 GPU（H100、B100、B200、GB200 等）高度依赖 CoWoS 产能。这是过去两年 AI GPU 放量的关键瓶颈之一。

利好：TSMC、HBM、先进封装设备、载板、中介层、封测、材料。

19. Glass Core：玻璃核心载板

它是什么？用玻璃作为封装基板核心材料，未来可能替代部分有机 ABF 载板。和 Glass Interposer 不同——Glass Core 更像是把封装基板中间的"骨架"换成玻璃。

优势：尺寸稳定性好、平整度好、适合高密度布线、热稳定性好、可能支持更大封装。

节奏偏慢：这条线目前仍偏长期。Intel、Samsung、AMD 均有探索，但真正大规模替代 ABF 不会太快，不能当成 2026 年主线。

20. ABF：Ajinomoto Build-up Film，ABF 载板材料

它是什么？高端封装基板里的核心绝缘材料。高性能 CPU、GPU、AI 加速器都需要 ABF 载板。

和玻璃的关系：更现实的路径：CoWoS/硅中介层先升级 → 玻璃 Interposer 进入先进封装 → Glass Core 未来再挑战 ABF 载板部分市场。短期不会马上颠覆。

六、产业链关系图

AI 集群互联链：

GPU / ASIC 算力提升
    → HBM 数量增加、I/O 密度提升
    → CoWoS 面积压力上升
    → 玻璃 Interposer / TGV / 翘曲控制

高速互联链：

AI 集群规模扩大
    → GPU 之间、机柜之间数据交换暴增
    → 800G / 1.6T 光模块放量
    → EML / PD / DSP / TIA / Driver / FAU 紧缺
    → NPO / CPO / OCS / 轻相干演进
