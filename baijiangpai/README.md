# 百将牌研究库

正式地址：https://www.xxyalpha.cn/baijiangpai/

静态 HTML / CSS / JavaScript，无框架、运行时依赖、外部字体、分析埋点或截图资源。只修改本目录，不影响投资主站。数据与功能分离，支持离线打包。

## 文件分工

- `data.json`：公开资料的可维护快照，包括来源日期、证据范围、技能、三座次策略、冲突和历史档案。不含个人余额、原始研究报告或截图。
- `data.js`：由 JSON 生成的浏览器数据，以免依赖 fetch，使离线文件也能运行。
- `index.html` / `style.css`：导航、元信息、响应式排版。
- `app.js`：目录、深链接、对照、研究文章、版本记录、本地复盘。
- `logic.js`：检索、净变化、回撤与备份校验纯函数，可独立测试。

## 日常维护

1. 更新 `data.json` 的指定武将，保留旧来源和原日期。规则、用户实测、研究推断分开；局部补丁不拼造全套技能。新截图比旧介绍更晚时保留冲突。没有资料不编次数。
2. 相同点数或花色无实战差别时，不增加无意义待测问题。已空手立即结束是通用口径，不能反复当作每将未知项。
3. 运行 `python3 tools/package_local.py` 同步 `data.js`。`build_data.py` 是本轮从旧库和审定研究输入导入的工具，不是日常维护必需依赖。
4. 同步 `index.html` 的资源版本后做语法、数据与浏览器检查。检索日期与实际内容更新日期必须区分。

```sh
node --check app.js
node --check logic.js
node tools/test_logic.cjs
```

浏览器检查需要可用的 Playwright 模块及 Chrome，可通过环境的 `NODE_PATH` 定位依赖；不安装进项目。启动站点根目录的静态服务器后运行 `node tools/test_browser.cjs`。默认 URL 为 `http://127.0.0.1:8847/baijiangpai/`，可用 `BJP_QA_URL` 指定其他测试地址。QA 使用独立临时浏览器，只录入测试数据，不连接个人浏览器。

离线打包：`python3 tools/package_local.py --offline /absolute/output/library.html`。离线文件的个人记录与正式站不是同一存储空间；不同浏览器对 file:// 存储支持不同，仍应导出备份。

## 复盘口径与隐私

个人记录只存在当前浏览器 `bjp-journal-v2` 本地存储，本站没有上传接口，不自动跨设备同步。净收益=结束−开局−外部净流入，开局应是入场扣费前；余额已含费用时不重复扣费。缺任一余额不进入统计，0为有效余额。胜率分母仅为余额齐全且填明胜负的局。最大回撤按日期排序后的累计净收益计算，起点为0。

恢复备份先验证 schema/字段/范围/ID，用户确认后替换；删除单条也需确认。JSON是可恢复备份，CSV仅作查阅，不实现CSV导入。不要将用户私人备份提交到仓库。当前公开数据中的 `battleSamples: 0` 只反映本轮提供的源表为空，不会随浏览器私人记录改写。

## 发布边界

用户已授权本轮成品正式发布。提交仅覆盖 `baijiangpai/`，基于当前远端 main，保留其他模块。必须分别确认推送、部署、线上资源与实际浏览器行为，不以本地测试或 commit 替代上线证明。源PDF含个人叙述，Excel为私人记录模板，均不作为公开下载上传。
