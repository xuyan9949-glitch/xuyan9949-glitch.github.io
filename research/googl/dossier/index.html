GOOGL

Alphabet 个股档案

搜索现金牛 · AI 搜索入口 · Google Cloud · 重资本 AI 基础设施

核心矛盾
Search 健康，Cloud 极强，CapEx 极高，FCF 承压。真正决定估值的是：AI 能否扩大 Search，Cloud 能否消化巨额 CapEx，FCF 能否在 2027 年以后重新抬头。

0. 执行摘要

一句话判断
Alphabet 正从“轻资产互联网广告垄断者”，变成“广告现金牛 + AI 搜索入口 + 全球第三大云厂商 + 重资本 AI 基础设施运营商”。

当前不能简单用 17× TTM PE 判断便宜，因为 2026 Q2 有约 $99B 股权投资未实现收益，显著抬高 GAAP EPS。

核心业务仍强：Q2 收入 $119.8B，+24%；Search +17%；Google Cloud +82%；经营利润率约 34%。

最大矛盾在现金流：2026 CapEx 指引提高到 $195–205B，Q2 单季 FCF 约 -$5.9B。

关键验证：AI Search 是否扩大查询与广告变现，Cloud EBIT 与 Search EBIT 增量能否跑赢新增 CapEx。

1. 一句话看懂公司

Alphabet 的主线不是“搜索公司是否过时”，而是“搜索入口 + AI 能力 + Cloud 基础设施”能否形成新的资本回报闭环。

核心公式
过去：搜索 → 流量 → 广告 → 现金。现在：入口 → Gemini → 广告 + Cloud + 企业 AI → 算力再投资。

10. 估值框架

不要直接使用 reported TTM PE ~17×，因为它被非经营性投资收益扭曲。

更合理做法：Normalized EPS × Normalized PE，当前更接近 high-20s PE。

FCF 交叉验证：TTM FCF yield 约 1.3%，若 CapEx 高峰不可逆，则估值并不便宜。

真正的 bull case 是：今天的 CapEx 是 growth CapEx，未来转化为 Search + Cloud EBIT。

一句话
GOOGL 的期望收益，不来自 17× PE 的“表面便宜”，而来自 AI CapEx 兑现后的盈利与 FCF 再抬升。

12. 核心催化剂

AI Search 变现被证明：AI Mode 扩大查询与广告库存。

Cloud 持续 >40–50% 增长，且利润率保持 30%+。

管理层暗示 CapEx 2027/2028 增速放缓。

Gemini Enterprise、Workspace、Vertex、Agent 形成可观 ARR。

Search / AdTech 监管尾部风险下降。

13. 最大风险

风险 含义
AI Search 经济模型恶化 Cost/query ↑↑，Ads/query ↓。
CapEx 永久化 AI 军备竞赛吞噬 FCF。
Cloud 产能上线后需求不足 今天缺算力，明天可能缺需求。
监管结构性 remedy Search default、AdTech、DMA。
模型落后一整个代际 企业 AI workload 流向 Azure / AWS / OpenAI / Anthropic。


14. 当前市场争议

AI 到底增强 Search，还是慢性蚕食 Search？

Cloud +82% 是结构性新周期，还是靠 CapEx 堆出来的低资本效率收入？

$195–205B CapEx 是阶段性高峰，还是新常态？

17× PE 是低估，还是会计错觉？

Google 是 AI winner，还是 AI defender？

15. 股性特征

中等波动成长股：低于高 Beta AI/半导体股，高于传统 Mega Cap。

财报日容易 Gap：现在市场看 Cloud growth、CapEx、FCF、Search，而不是单纯 EPS beat。

经常走慢趋势：突破、回踩、趋势延续比单日暴涨暴跌更常见。

监管新闻会造成瞬时折价，但持续趋势取决于结构性 remedy。

16. 与板块相关性

与“云—光—存”的关系
GOOGL 和 NVDA 股价相关性不一定高，但 GOOGL CapEx 是下游 AI 硬件需求的核心源头：TPU/GPU → HBM/DRAM/SSD → Networking/Optics → Power/Cooling。

17. 宏观敏感因素

经济增长：影响广告主预算。

利率：影响 Mega Cap PE 与长期现金流折现。

企业 IT 支出：直接影响 Cloud。

美元：Alphabet 海外收入接近一半。

电力价格：数据中心越来越像能源资产。

芯片、网络设备、光模块、电力供应：决定 AI capacity。

AI / 隐私 / 反垄断监管：长期 friction。

21. 哪些情况意味着逻辑证伪

Search 增速连续跌到 <5%，且份额持续下降。

AI query 大增，但 Revenue/query 下降、Cost/query 上升，利润率被侵蚀。

Cloud 增速降到 <30%，但 CapEx 仍 >$200B。

2027 产能上线后，FCF 仍长期低迷或为负。

持续债务、发股、优先股融资，回购长期停止。

Cloud margin 从 30%+ 明显下滑。

Gemini 持续落后一整个代际，企业 AI workload 外流。

22. 最新动态

动态 投资含义
AdTech remedy 温和于极端拆分 美国法院未强制出售 AdX，采取行为性 remedies；Google 仍计划上诉。
AI 基建继续加码 芬兰约 $15B AI 基础设施投资，电力成为关键约束。
企业 Cloud 客户继续推进 BNP Paribas 五年 Cloud + AI 合作，但敏感数据仍有迁移限制。
Gemini 持续迭代 Gemini / Private AI Compute / Enterprise AI 产品继续更新。
欧洲监管摩擦仍在 爱尔兰位置数据隐私罚款显示 friction 长期存在。

最终结论

压缩版
Search：健康。Cloud：极强。CapEx：极高。FCF：承压。以后研究 GOOGL，只盯四个数字：Search Growth → Cloud Growth → CapEx → FCF。
牛熊分水岭
如果新增 AI CapEx 能转化为新增 EBIT，GOOGL 会从传统 Search 巨头重新评级为 AI Infrastructure + Platform 公司。如果不能，Google 将从轻资产高 ROIC 模型滑向重资产、低 FCF、资本效率下降的 Mega Cap。
